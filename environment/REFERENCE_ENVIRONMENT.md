# Software environment

The exact Conda environment used for the archived analysis is provided in `environment.yml`. A complete `pip freeze` snapshot is also provided in `requirements.txt`.

Principal package versions in the archived environment are:

- Python 3.11.15
- NumPy 2.4.6
- pandas 3.0.3
- SciPy 1.17.1
- scikit-learn 1.9.0
- LightGBM 4.6.0
- Matplotlib 3.10.9
- joblib 1.5.3
- requests 2.34.2

For convenience, the principal packages are also listed in `requirements-reference.txt`. The Conda environment file is the authoritative environment specification for reproducing the analysis.
